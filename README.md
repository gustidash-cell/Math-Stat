## 📚 Struktur Materi &amp; Alokasi Pertemuan

Modul ini disusun berdasarkan **RPS Berbasis OBE 2026** dan rujukan utama **Walpole, Myers, Myers &amp; Ye (2011)** *Probability &amp; Statistics for Engineers &amp; Scientists* (9th ed.):

| Pertemuan | Kode | Topik Pembelajaran | Sub-CPMK / Capaian Pembelajaran |
| :--- | :--- | :--- | :--- |
| **Pertemuan 1** | `P1` | **Konsep Dasar Peluang** | Sub-CPMK 1.1: Mampu menjelaskan dan menerapkan prinsip dasar peluang (Eksperimen, Ruang Sampel, Aksioma Kolmogorov, Teorema Turunan). |
| **Pertemuan 2** | `P2` | **Peluang Bersyarat &amp; Saling Bebas** | Sub-CPMK 1.2: Mampu menjelaskan dan menerapkan peluang bersyarat $P(A\|B)$ dan peristiwa saling bebas ($P(A \cap B) = P(A)P(B)$). |
| **Pertemuan 3** | `P3` | **Hukum Peluang Total &amp; Teorema Bayes** | Sub-CPMK 1.3: Mampu menjelaskan dan menerapkan Partisi Ruang Sampel, Peluang Total, dan Teorema Bayes $P(B_r\|A)$. |
| **Pertemuan 4** | `P4` | **Peubah Acak &amp; Distribusi Peluang** | Sub-CPMK 2.1: Mampu menjelaskan dan menyelesaikan masalah peubah acak diskrit &amp; kontinu $X: S \to \mathbb{R}$. |
| **Pertemuan 5** | `P5` | **Fungsi Kepadatan Peluang (FKP) &amp; Kumulatif (CDF)** | Sub-CPMK 2.2: Mampu merumuskan PMF $p(x)$, PDF $f(x)$, dan CDF $F(x) = P(X \le x)$. |
| **Pertemuan 6** | `P6` | **Ekspektasi Matematika &amp; Varians** | Sub-CPMK 2.3: Mampu menghitung Harapan Matematika $E[X]$, Ekspektasi Fungsi $E[g(X)]$, dan Varians $Var(X) = E[X^2] - (E[X])^2$. |
| **Pertemuan 7** | `P7` | **Review &amp; Integrasi Konsep UTS** | Sub-CPMK 2.4: Mampu mengintegrasikan seluruh materi Pertemuan 1–6 dalam paket soal latihan komprehensif persiapan UTS. |
| **Pertemuan 8** | `UTS` | **Evaluasi Tengah Semester (UTS)** | Evaluasi CPMK 1 &amp; CPMK 2. |

## 💻 Fitur Modul Web HTML (`index.html`)

- 🎯 **Navigasi Tab Interaktif**: Beralih antar pertemuan (P1–P7) tanpa mereload halaman.
- 📐 **Format Rumus Presisi (MathJax 3)**: Semua persamaan dan simbol matematika diproses secara dinamis.
- 📖 **Bukti Teorema Interaktif**: Klik *Lihat Bukti* (`<details class="proof">`) untuk mempelajari langkah pembuktian deduktif.
- 💡 **Soal Terbimbing &amp; Kunci Jawaban**: Disertai latihan interaktif dan refleksi konsep.
- 📱 **Desain Responsif &amp; Modern**: Tipografi elegan (*Fraunces*, *Source Serif 4*, *JetBrains Mono*) dengan palet warna khusus.
